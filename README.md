# Adam's Vinyl Record Collection

This repository contains a collection of vinyl records owned by me, Adam. It was initially populated via photos given to AI, so some albums with wonky spines were missed. I'll add missing ones as I find them.

The point of this repository is to keep a local copy of the collection, and scripts to push it to Discogs. Might add metadata or something later. Might add it to my website or something. Who knows.
